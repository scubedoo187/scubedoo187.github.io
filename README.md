# site/

WeatherWays 의 공개 정적 사이트 원본이다. 이 폴더의 내용이 그대로 GitHub Pages 사용자 사이트 저장소 `scubedoo187/scubedoo187.github.io` 의 루트로 배포되어 https://scubedoo187.github.io/ 에서 서비스된다(개인정보처리방침: https://scubedoo187.github.io/weatherways/privacy/ , 영문 `/weatherways/privacy/en/`). 방침 본문의 원본은 `docs/privacy-policy.md` 이고, 바꿀 때는 원본과 ko/en 두 HTML 을 함께 갱신한다. `{{DEVELOPER_NAME}}` 은 개발자명 확정 전 자리표시자다(각 언어 페이지에 한 번씩). `.nojekyll` 은 Jekyll 처리를 끈다. AdMob 게시자 ID 가 정해지면 `app-ads.txt` 를 이 폴더 루트(사이트 루트)에 추가한다.
